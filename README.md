# CandySim website

The official site for the CandySim Minecraft server. Join at **CandySim.minehut.gg**.

Live at https://medsaadani0.github.io/candysim-site

`index.html` is a build output. The source lives in the server repository under `candysim-site/`; rebuild with `python3 build.py` there and copy `dist/index.html` here.
